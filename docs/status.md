 ### What was built                                                                                                                                                                                                                         
                                                                                                                                                                                                                                            
 A complete React 19 + Vite 8 + Tailwind v4 project in /Home1/project/skills-catalog/ that renders the 324-line skills-catalog.md (198 skills, 10 categories) as a polished, navigable single-file web page.                                
                                                                                                                                                                                                                                            
 ### Key features                                                                                                                                                                                                                           
                                                                                                                                                                                                                                            
 - Technical template: Three-column layout (TOC nav + content + "on this page" outline), cool gray + blue palette                                                                                                                           
 - Sticky header with title and theme toggle (light/dark/system)                                                                                                                                                                            
 - Table of Contents: Extracted from H2–H4, active-section highlighting via IntersectionObserver                                                                                                                                            
 - Dark mode: Full two-layer token pattern (:root variables + @theme inline bridge)                                                                                                                                                         
 - WCAG 2.2 AA compliant: Verified by axe-core in both light and dark modes                                                                                                                                                                 
 - Responsive: Desktop three-column, mobile-ready structure                                                                                                                                                                                 
 - Accessible: Skip link, focus-visible rings, reduced-motion support, semantic landmarks                                                                                                                                                   
 - Error boundary: Graceful fallback if markdown fails to render                                                                                                                                                                            
 - Tag registry: Infrastructure ready for badge annotations (none in current content)                                                                                                                                                       
                                                                                                                                                                                                                                            
 ### How to use                                                                                                                                                                                                                             
                                                                                                                                                                                                                                            
 ```bash                                                                                                                                                                                                                                    
   cd /Home1/project/skills-catalog                                                                                                                                                                                                         
                                                                                                                                                                                                                                            
   # Development server                                                                                                                                                                                                                     
   npm run dev                                                                                                                                                                                                                              
                                                                                                                                                                                                                                            
   # Production build → dist/index.html (single self-contained file)                                                                                                                                                                        
   npm run build                                                                                                                                                                                                                            
                                                                                                                                                                                                                                            
   # Preview the build                                                                                                                                                                                                                      
   npm run preview                                                                                                                                                                                                                          
                                                                                                                                                                                                                                            
   # Run all tests                                                                                                                                                                                                                          
   npm run test                    # Unit + integration + bundle-size                                                                                                                                                                       
   npx playwright test             # Accessibility (axe)                                                                                                                                                                                    
                                                                                                                                                                                                                                            
   # Typecheck                                                                                                                                                                                                                              
   npm run typecheck                                                                                                                                                                                                                        
 ```

 ### To update the content                                                                                                                                                                                                                  
                                                                                                                                                                                                                                            
 Replace src/content/document.md with any markdown file and rebuild — the pipeline handles frontmatter, tables, headings, links, and code blocks automatically.
